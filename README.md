## Projects

### Folio Local PDF Suite
An offline-first PDF toolkit for Windows. View, merge, split, reorder, convert, compress, annotate, and protect PDFs with local processing and Arabic/English support.

- Built with React, TypeScript, Vite, PDF.js, pdf-lib, and qpdf WebAssembly
- Project status: core PDF tools and the first two development phases are implemented; broader file-based verification is ongoing
- [Repository](https://github.com/iraqi-man1/folio-local-pdf)

### BrightSmile Dental Clinic Manager
A multi-tenant workspace for dental clinics to manage day-to-day clinical and business operations.

- Track patients, medical histories, allergies, visits, X-rays, and clinical images
- Plan treatments with procedures, prices, sessions, and progress; record payments, balances, and printable receipts
- Schedule appointments on day, week, and month calendars, with drag-and-drop booking
- Review clinic activity, revenue, inventory alerts, reports, and staff access by role
- Built with Next.js, TypeScript, Tailwind CSS, Recharts, and Supabase; PostgreSQL Row Level Security scopes records to each clinic
- Runs as an interactive in-memory demo without Supabase configuration; connect a Supabase project for persistent accounts and data
- [Repository](https://github.com/iraqi-man1/Dental-Clinic-Manager)

### Northstar Budget
A bilingual personal finance app for tracking income, expenses, savings accounts, and financial goals.

- See balances, monthly comparisons, cash flow, spending categories, and recent activity
- Create and manage income, expenses, savings, goals, sources, and categories
- Make guarded deposits, withdrawals, transfers, and goal contributions with atomic database operations
- Supports Arabic and English, native RTL layout, light/dark themes, and Iraqi dinar formatting
- Built with React, TypeScript, Vite, and Supabase Auth/PostgreSQL; user-owned records are protected with Row Level Security
- Includes JSON backup and filtered transaction CSV export
- [Live app](https://northstar-budget-ali-ahmed.netlify.app) · [Repository](https://github.com/iraqi-man1/northstar-budget-tracker)
